- **Responsive Design**: Mobile-friendly dengan desain modern

- **Experience Timeline**: Timeline interaktif pengalaman kerja

## Deploy ke GitHub Pages

1. Clone atau buat repo dengan nama `portoTeguh`
2. Copy semua file ke dalam repo
3. Push ke branch `main`
4. GitHub Pages akan otomatis serve dari: `https://username.github.io/portoTeguh/`
